# Roadmap

Where ctdev is going. One page per idea:

- [The fleet](fleet.md): an agent on each managed device, reporting to a central dashboard and
  taking commands from it.
- [The phone app](phone-app.md): so a phone can be a managed device.
- [UniFi network setup](unifi-network-setup.md): ctdev sets up a UniFi network to a standard.
- [AI capabilities](ai-capabilities.md): ctdev reasons about situations it was not programmed for,
  without a new release.
- [The docs site](docs-site.md): this repo's Markdown, published as a website.

Each page says what the idea is and why ctdev wants it, and links to its Linear project where one
exists. There is no progress column and there are no dates on purpose: a status written in a file
goes stale the day after it is written. Progress and design are kept in Linear, along with every
other spec and design document for this repo. A Linear link needs a seat to open, so each page is
written to be read without following it.

ctdev is an internal tool. Nothing here is a commitment to anyone outside Conner Technology.

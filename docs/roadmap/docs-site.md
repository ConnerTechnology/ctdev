# The docs site

## What it is

This repo's Markdown, published as a website at ctdev.connertechnology.io. The generator is not
chosen.

## Why ctdev wants it

The docs are written for operators and for a client's IT contact, and a website is an easier place
to read them than a repository. The docs are kept as plain Markdown with relative links and one
topic per file, so a site can be built from them without moving anything.

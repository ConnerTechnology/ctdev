# The fleet

## What it is

A fleet is the set of devices one owner manages together with ctdev, with its own dashboard and
users and no view into any other fleet. A fleet spans many networks.

The idea is an agent on each managed device that reports the device's health to a central
dashboard and runs commands sent from it, so that what ctdev does at a device can also be done
from the dashboard by a person who has been given permission to do it.

## Why ctdev wants it

ctdev manages the machine you are sitting at. Knowing how every other device is doing means signing
in to each one, or to each separate tool that watches it. The fleet gives one place to look: every
managed device, what it is doing, how it has been doing over time, and the actions you may take on
it.
